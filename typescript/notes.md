#### Learn these topics in this order:
1. System prompts — role, goal, instructions, constraints.
2. Message hierarchy — system, developer, user, and tool messages.
3. Prompt engineering — writing clear, reliable instructions.
4. Tools and tool calling — letting an agent interact with software.
5. Agent loops — observe, decide, act, and repeat.
6. Deep Agents — planning, subagents, memory, and filesystem tools.
